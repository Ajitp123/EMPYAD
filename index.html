⌨️ Keyboard Shortcuts (Computer)

Ctrl + ← / Ctrl + → — Pichla / Agla tab

Attendance: Alt+Y = Year select, Alt+M = Month select, Alt+S = Save, Alt+U = Unlock. Cell ke andar Arrow keys se kisi bhi date/employee par jump karo.

Year Summary: Alt+Y = Year select, Alt+R = Refresh

Grand Total: Alt+F = From Year, Alt+O = To Year, Alt+E = Employee select, Alt+T = Show Total

Salary Rates: Alt+Y = Year select, Alt+F = From Month, Alt+O = To Month, Alt+M = Save This Month, Alt+L = Save Full Year, Alt+R = Save From Month → To Month
